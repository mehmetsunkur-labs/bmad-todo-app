## Measured numbers

From the two full verification runs of `pnpm test:e2e` after the review fixes (both green: 99 passed, 2 expected Firefox skips). Each value is also a test annotation in the HTML report (`e2e/playwright-report`).

| Action p95: add                               | ≤ 100 ms   | 49.8 ms       | 50.4 ms       | 52.3 ms       | 52.9 ms       |
| Action p95: toggle                            | ≤ 100 ms   | 47.8 ms       | 48.3 ms       | 49.2 ms       | 50.3 ms       |
| Action p95: edit-save                         | ≤ 100 ms   | 35.2 ms       | 36.7 ms       | 36.8 ms       | 39.6 ms       |
| Action p95: delete                            | ≤ 100 ms   | 52.6 ms       | 41.5 ms       | 44.2 ms       | 56.0 ms       |
| API p95 (server `responseTime`, 200 requests) | ≤ 300 ms   | 10.8 ms       | —             | 9.2 ms        | —             |

**Measurement note.** The first timing runs showed add and toggle p95 at 105–138 ms. A CPU profile of the page showed the time going to Playwright's trace recorder (`captureSnapshot` / `visitNode`), which snapshots the whole 1,000-row DOM in the page's main thread around each action, 60–250 ms at a time; the app's own work per toggle was under 10 ms. `performance.spec.ts` now turns tracing off (`test.use({ trace: "off" })`, with a comment saying why). No threshold changed and no action was left out.

## Screenshots

Taken with a throwaway Playwright spec against the same stack (not committed; screenshots stay out of git), in light and dark mode at 1280 px and 360 px, for Loading (skeleton after 300 ms), Empty, Populated with Completed Todos, Inline edit, a failure toast and Load error. The mockup was rendered the same way at 1280 px.

- **Populated (light, dark):** one centred 576 px column; "Todos" header; Add row with the teal Add button; rows with a 16 px checkbox on the column's left edge, the Description 50 px in, Created At below it, and a 1 px divider. Completed rows show a filled teal box, line-through and muted text. Long URLs wrap. Row actions are hidden until hover or focus at 1280 px and always shown at 360 px. Matches the mockup's panels 1–3 once G-5 to G-8 were fixed.
- **Inline edit (1280, 360):** a bordered Textarea, all text selected, focus ring in `ring`, text starting where the Description did; Created At switches to "Created {date, time}"; Edit and Delete stay. Matches panel 3 after G-6 (see G-13 for what is logged).
- **Empty / Load error:** centred `empty-title` headline and 14 px muted body; Load error adds the secondary "Try again"; the Add row is disabled at 50%. Matches panels 4a and 5 after G-7.
- **Loading:** four skeleton rows with a 16 px square, a text bar and a meta bar, under the disabled Add row. Matches panel 4b after G-4.
- **Toast:** Sonner's neutral popover surface with the destructive CircleX, bottom-right at 1280 px and bottom-centre at 360 px. Matches panel 6.
